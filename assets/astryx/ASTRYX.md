## Astryx is agent friendly

Astryx was built for people and agents together. The API, docs, and CLI were designed together from the same reference material, so a person and an AI agent build the same way.
- The CLI carries component documentation. `astryx docs` answers how the system works. `astryx component --list` lists what exists.
- The CLI ships a machine-readable manifest, like an OpenAPI spec for the CLI, for every command.
- `npx @astryxdesign/cli init` writes the Astryx guide to `AGENTS.md` / `CLAUDE.md` so agents build with Astryx instead of guessing.
- Every component follows the same naming, prop, and composition rules, and every one is documented, so an unfamiliar component behaves predictably.
- Themes are CSS custom property overrides. Swap token values and every component restyles with no component code change.
- Open internals: building blocks are exported directly. `swizzle` ejects full component source to own.
- No styling lock-in: override with `className` using Tailwind, CSS modules, or plain CSS.
- Design opinions live in docs and examples. Components give capability, not guardrails.

## How Arena uses these files in sea-tunnel-atlas v2

- Read `assets/astryx/AGENTS.md` first, then `assets/astryx/ASTRYX.md`, then `assets/astryx/tokens.json`.
- Use local files only. Do not run `npm install`, do not run `npx @astryxdesign/cli init`, do not fetch Astryx from npm or GitHub in this task. The files are already here.
- Link order in `index.html`, before `style.css`: `assets/astryx/reset.css`, `assets/astryx/astryx.css`, `assets/astryx/theme-neutral.css`, `assets/astryx/fonts.css`. Then `style.css` overrides with mapped tokens.
- Set `data-astryx-theme="neutral"` on the page scope, and keep `html[data-theme]` light/dark handling from `theme-neutral.css`.
- Map sea-tunnel-atlas values to Astryx tokens in `style.css`. Old palette #176d4e, #007CAD, #72c99e, #5cb8e0 is replaced. Old fonts Trebuchet MS / Verdana, and DejaVu Sans Mono / Consolas for data values only, map to `--font-family-body`, `--font-family-heading`, `--font-family-code`, and `--text-*` tokens. Keep mono for data values only.
- Key tokens to use first: `--color-background-body`, `--color-background-surface`, `--color-background-card`, `--color-text-primary`, `--color-border`, `--color-border-emphasized`, `--color-accent`, `--color-background-muted`, `--font-family-body`, `--font-family-heading`, `--font-family-code`, `--text-body-size`, `--text-heading-1-size`.
- Do not migrate to React. Astryx React components require React 19+. This site is static, no build, no bundler, Leaflet 1.9.4, vanilla JS. Translate the design language to plain CSS. If React is needed later, present it as a separate option with cost, test impact, and Vercel impact, and wait for maintainer approval.
- Final state: assets live only in `assets/astryx/`. Do not recreate a root astryx/ folder.
- Document every token mapping in sea-tunnel-atlas `AGENTS.md`, with old value, new Astryx token, CSS custom property, file, and line.
