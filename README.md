## Quick start

Run `python3 -m http.server 8000`, then open `http://localhost:8000`. No build step or API key is required. Leaflet, map tiles and optional places require network access. Select a marker to read its source. The seed is [`data/egress.geojson`](data/egress.geojson); see [data sources](DATA_SOURCES.md) for its verification limitations.

The GTFS transit layers are not yet populated: the agency hosts were unreachable during development. Run `python3 tools/gtfs_to_geojson.py` from a machine that can access them, after checking agency terms. The resulting feeds and external services still need validation. No deployment is configured.

Data is from public sources only, contains no SSI, and is for education and civic interest. Entering tunnels, shafts, or trackways is illegal and can kill you. Locations can be approximate or wrong; do not use this map for navigation or emergency response.
